# Regresso Imobiliária 🏡

**Sistema desktop de compra e aluguel de imóveis**  
Desenvolvido em **C puro + GTK 4**  
Grupo: Gabriel Rosa, João Nick, Matheus Maceno, Erick Alan.

### Funcionalidades entregues
- Tela principal com barra lateral e filtros
- 12 imóveis reais com fotos de alta qualidade
- Cards modernos com hover e sombra
- Clique no imóvel → tela de detalhes completa (foto grande, preço, descrição, quartos, área)
- Design 100% personalizado (CSS + logo próprio)
- Totalmente funcional no Windows

### Estrutura do projeto
- src/          → código-fonte
- assets/       → imagens e logo
- bin/          → executável

### Divisão de tarefas

- [João Nick] → Design visual completo (style.css, cores, cards modernos)  
- [Matheus Maceno] → Estruturas de dados, array de imóveis, passagem de parâmetros  
- [Erick Alan] → Organização do repositório GitHub, pastas, README e build

### Tecnologias usadas
- Linguagem: C99
- Interface: GTK 4
- Ferramenta auxiliar: GitHub Copilot (usado como assistente de código — todas as decisões e revisões foram nossas)

### Como executar
1. Abra a pasta `bin/`
2. Execute `app.exe`
